FarmFresh — Direct Farmer to Consumer Marketplace

Empowering Farmers with Fair Margins & Providing Consumers Pure Organic Produce

🚩 Project Vision (मराठीत माहिती):
FarmFresh ha ek modern agri-tech e-commerce platform ahe. Yachya madhyamatun **Shetkari (Farmer)** aapla taaza shetmaal kontyahi dalal (middlemen) shivay direct **Grahak (Customer)** la viku shakto. Shetkaryala purna nafa milto ani grahakala taaja maal kami daamat milto.

👨‍🌾 Farmer Empowerment

Farmers list produce with custom prices, manage inventory, and directly accept or cancel customer orders.

🛒 Consumer Freshness

Customers explore categories, add to cart with live calculations, and place verified doorstep delivery orders.

🛡️ Admin Oversight

Platform admins moderate products, verify farmer profiles, inspect order splits, and manage customer inquiries.

Problem Statement vs Solution

Why FarmFresh? (सध्याची समस्या आणि उपाय)

Solving the broken traditional agricultural supply chain in India.

🚩 Samasya Kay Hoti? Traditional market madhe agent/dalal 30% te 50% commission ghetat, jyana shetkaryala kami bhav milto ani maal customer paryant pocheparyant shila hoto. FarmFresh he dalal completely hatavto!

Traditional Market Flaws

  • Heavy middlemen cuts (30%–50% lost in transit).
  • Produce stored in mandi godowns for days, losing vitamins.
  • Rural farmers lack digital discovery and customer access.
  • No direct customer feedback or dynamic pricing power.

FarmFresh Digital Solution

  • 0% Brokerage: 100% price control stays with the farmer.
  • Direct harvest-to-home logistics ensures top freshness.
  • Web-based farmer dashboard accessible on mobile/laptop.
  • Live order notifications and clear status workflow.

System Design

3-Tier System Architecture & Data Flow

Clean separation of concerns with RESTful API communication.

[ Browser Client (HTML5 / CSS3 / ES6 api.js) ] │ ▲ │ │ HTTP/JSON REST API Requests & Responses ▼ │ [ Spring Boot Controller Layer (@RestController) ] ├── AuthController (/api/auth) ├── CustomerController (/api/customer) ├── FarmerController (/api/farmer) ├── AdminController (/api/admin) └── OrderController (/api/orders) │ ▲ ▼ │ [ Business Service Layer (@Service) ] ├── AuthService, OrderService, ProductService, AdminService │ ▲ ▼ │ [ Data Access Layer (@Repository - Spring Data JPA) ] └── CustomerRepository, FarmerRepository, ProductRepository, OrderRepository │ ▲ ▼ │ JDBC SQL Execution via HikariCP Pool [ MySQL 8.0 Database (farmfresh) ]
🚩 Kasa Chalto Flow? User browser madhun click karto -> `api.js` request Spring Boot chya Controller la pathavto -> Service layer madhe business logic verify hote -> Spring Data JPA marfat MySQL Database madhe data save kiva fetch hoto.
Database Design

Database Schema & Entity Relationships

Relational tables with historical snapshot protection.

👥 customers

id (PK), full_name, email (UK), password (BCrypt), mobile, city, state, status

👨‍🌾 farmers

id (PK), full_name, email (UK), password, farm_name, mobile, farm_address, city, pincode, status

🥦 products

id (PK), farmer_id (FK), name, category, price, quantity, unit, image_url (LONGTEXT), status

📦 orders

id (PK), customer_id (FK), name, phone, email, address, city, state, pin, subtotal, delivery_fee, total, status

📋 order_items

id (PK), order_id (FK), product_id (FK_NULL), product_name, farmer_name, price, quantity, unit

✉️ contact_messages

id (PK), name, email, subject, message, created_at, status

💡 Smart Feature (Historical Snapshots): `order_items` table madhe product chi daam ani naav order kartana snapshot mhanun save hote. Mhanje shetkaryane nantar bhav badalla tari juni order history bilkul chukat nahi!

Security Architecture

Engineering Feats

Key Technical Challenges & Fixes Applied

Critical bugs identified, analyzed, and solved during development.

1. Image Truncation SQL Error

Problem: Base64 images exceeded 255 chars in VARCHAR.
Fix: Upgraded MySQL column to LONGTEXT and added @Lob annotation in Product.java.

2. Foreign Key Cascade Crash

Problem: Deleting ordered products threw FK constraint error.
Fix: Set ON DELETE SET NULL on MySQL foreign key & added JPA unlinking in ProductService.

🚩 Taantrik Adchani & Solution: Photo save kartana 'Data too long' error yet hota to `LONGTEXT` karun solve kela. Product delete kartana FK error yet hota to `ON DELETE SET NULL` karun solve kela.
